2026-11-10。用户授权：先整理无需额外美术素材的改进，再由 subagents 实现并在适当节点提交。本轮以已接入 Delivery01/02 的 M2 试场为基础；保留现有原画、物理规则、场景摆放和第一章范围。原始 V1.0 不改写。

## 本轮实施清单

| 工作组 | 无需额外交付的实施内容 | 验证重点 |
| --- | --- | --- |
| 碰撞事件与接入 | 补真实命中的材质类别、入射/出射方向、速度与发射标识；提供带反弹折点的实际路径；独立反馈组件接收已完成的玩法事件 | 预测无副作用；一次反弹预算、穿墙/收片/嵌入结果不变；同一目标不重复结算 |
| 碰撞视觉 | 星弹沿实际路径的短尾迹、撞点定向星闪/石粉、星体视觉挤压恢复、入槽/收集/失败重组；利用已有鼓受击帧，补琴体轻振与陶碎几何 | 命中点与法线匹配；效果不改变 Collider/根节点；尾迹不跨过反弹点或瞬移连线 |
| 声音样板 | 程序合成可辨的石击、拨弦、膜鼓、陶裂、嵌槽与收集小样，事件接入与分层/去重；沿用 Music/SFX Mixer | 乐器不叠石击；定音保持统一音集；暂停/复位/切关无残留，音量设置有效；合成小样不冒充外部正式母版 |
| 瞄准、星影与 HUD | 星点/箭头/反弹与终止形状、蓄力进度/满蓄；占槽/锁定/召回的形状与回流；图形碎片进度和单影状态 | 使用共享查询；四态不只依赖颜色；召回结束前承重轮廓保留；HUD 按真实 ID 与当前会话更新 |
| 镜头与既有界面 | 克制的定向碰撞冲击与可调强度；减轻走路/蓄力构图切换的突变；现有菜单按钮状态、边饰与反馈一致化 | 镜头不积累漂移、瞬移清历史、暂停冻结；720p/1080p/16:10；不遮目标与功能控件 |

运行时使用程序几何、既有 Sprite 与合成 PCM；不调用 AI 生图，不复制/修改外部原稿，不添加第三方插件。必要的 Unity `.meta` 由 Windows Editor 导入生成并回写。新增程序视觉属于技术反馈，正式绘本特效、角色动作、建筑/门/桥原画、分层琴弦、陶墙状态和录制音效仍待原交付清单验收。

本轮不加入改变全局时钟的命中停顿。先完成不会改变飞行与召回时序的形变、声音、粒子和镜头冲击；hit-stop 留作后续独立试调。神庙建筑、关卡空间重排和新角色动作不在本轮程序替代范围；不能靠拉伸现有原画冒充新交付。

## 分工与集成约定

主 agent 负责命中/路径数据、镜头、接入、文档、Windows 同步、Editor 运行验证和提交。三个 subagents 分别负责碰撞视觉、声音、瞄准/星影/HUD。只有主 agent 驱动 Windows Editor 与 Git 提交，避免热重载和同时修改场景。各 agent 在 WSL 编辑分配文件，保留其他人的工作。

反馈以已完成的真实命中/进度事件触发。飞行体继续由原 shape sweep/Kinematic motor 控制，人体继续由原 Dynamic Rigidbody2D 控制；视觉变形只作用 Visual，音画不决定收集、开门、破墙、嵌入或恢复控制。声音与视觉的生命周期必须覆盖暂停、普通失败、谜题复位、重开和卸载。

## 实现与可调整项

- 实际路径每步包含起点/反弹中心/终点；impact 包含真实材质、法线、入射/出射方向、蓄力、速度与 shot ID。只读预测没有任何音画/进度副作用。首次破墙完成独立通知，鼓波多墙也走同一路径。
- `ImpactFeedbackView` 使用单动态 Mesh、24 个事件槽、最多 96 个路径点；短尾迹寿命 0.14 s，星闪/定向石粉约 0.2–0.36 s、陶片 0.6 s。`PlayerView` 独占星体 Visual 的约 0.19 s 挤压恢复；`InstrumentArtView` 加 0.36 s 琴体轻振与鼓波衰减。以上均为样机调参值。
- `CoreAudioFeedback` 使用 12 个复用合成片段、两个 AudioSource，固定 D/A 音色与 D5/F5/A5 进度，陶裂合簇 75 ms。嵌槽/召回由原 `ShadowFeedback` 负责；没有额外音频中间件或 WAV。
- `TrajectoryPreview` 星点/箭头/反弹标与终止形状；`GameplayFeedbackView` 独立蓄力/满蓄形状、单影四态/锁形/召回回流；`ProceduralHudGraphic` 按当前允许 ID 显示碎片。图形使用既有 uGUI、Input Actions 实例绑定，静音/灰度也保留形状差异。
- 相机跟随基准与冲击偏移分开，0.18 s 内衰减；`ChapterCamera2D.ImpactStrength` 默认 0.65，可设 0。行走/瞄准垂直锚点 0.30→0.42 渐变，瞄准偏移平滑过渡。旧相机的房间边界、dead zone 与每帧不越过目标保留。菜单只给既有按钮加金边与状态色，不改回调/布局。

精确文件与 SHA-256 见 [manifest](procedural-feedback-manifest.json)，所有新增技术形状按 [Checklist §11](06-占位美术替换Checklist.md) 跟踪。外部原画、Atlas UV、PPU、pivot、Prefab/Scene 物理和稳定 ID 未改；制作/运行编辑器共用组件自动生效。

### 最终运行结果

Windows Editor / RTX 4060 Laptop、键鼠，Gallery 实际 Input Actions 操作：走跳、满蓄/取消、收片、普通斜墙反弹、里拉开门、手鼓波首次碎陶墙、入槽/重组/1 秒召回与中途暂停。最终连续四弹的程序 impact 音调用 5 次（包含普通石两次、里拉两次、鼓一次），陶裂一次、收片一次，未叠通用乐器石声；飞行/返回时形状与尾迹保持独立。日志中的 `ImpactPlaybackCount=5` 只统计石面与乐器，socket 由原独立源负责。暂停召回 `progress delta=0`、支撑仍在、玩家/相机位移均为 0；停用相机期间重组后再启用，玩家回到视口 `(0.40,0.30)`。反馈结束后 `ActiveBurstCount=0`、`TrailPointCount=0`，运行片段 12 个，没有每次发射再生成资源。

Game view 实际分辨率 1280×720、1920×1080、1280×800，新增 HUD 未挡住开发/暂停控件；检查了标准视角、角色近景、满蓄/预测、命中/陶片、召回锁形与暂停。1920×1080/1280×800 在静音下读形状；当前 Gallery Camera 没有 `UniversalAdditionalCameraData`，`post=false`，原本未启用 Bloom，所以实际是无后处理可读性检查，没有强行给相机加组件。离线灰度复查星点/反弹/锁形/召回/碎片仍保留形状差别。音频实际调用、SFX 总线与样本峰值已检查（48 kHz mono、峰值 0.20/0.40/0.52）；本轮无法代替真实耳机/扬声器听感验收。
