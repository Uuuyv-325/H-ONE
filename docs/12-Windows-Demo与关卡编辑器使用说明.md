# H-ONE Windows Demo 与关卡编辑器使用说明

版本日期：2026-11-10。适用对象：附带游戏内关卡编辑器的 Windows x64 Demo。

## 1. 启动与内容

1. 将整个 ZIP 解压到一个普通文件夹，不要直接在压缩包内运行。
2. 双击 `H-ONE.exe`。不需要安装 Unity Editor。
3. 在主菜单点击“进入试场”，进入机关试场。首次启动可能需要等待初始化。
4. 推荐使用键盘、鼠标，以 1280×720 或更大的窗口运行。

请保留 `H-ONE.exe`、`H-ONE_Data`、`UnityPlayer.dll`、`MonoBleedingEdge` 等文件的相对位置，不能只分享 EXE。

这个版本用于体验和制作机制原型，包含主菜单、暂停菜单，以及发射反弹、星影平台/星桥、星石压板、里拉开门和手鼓碎墙试区。它尚不是正式第一关、第二关；没有完整的星座出口、下一关流程或排箫升降平台。

本 Demo 使用 Development Build，以保留 `Edit level` 和试场快捷导航；画面上的开发版标记属于正常显示。

## 2. 游戏操作

| 操作 | 按键 |
| --- | --- |
| 左右移动、侧推星石 | A / D |
| 跳跃 | Space |
| 蓄力 | 接地时按住 E |
| 瞄准 | 移动鼠标 |
| 发射 | 松开 E |
| 取消蓄力 | 鼠标右键 |
| 收回星影 | R，约 1 秒后完成 |
| 暂停、恢复 | Esc |

星弹飞行中不能转向，每次发射最多反弹一次；普通墙、里拉、手鼓共用这个次数。入槽会留下星影，本体约 0.5 秒后回到最后激活的安全星台；同时只能留一个星影。

碎片只能用星弹收集。压板只接受星石和星影，人形不能直接踩亮。普通失败保留碎片、已击碎的墙、里拉开启状态和已放星影；压板和桥始终随当前占用变化。

暂停菜单中的“重置当前谜题”撤回星影、复位当前星台所属组的可复位物体，保留收集和锁存进度；“重新开始试场”清空本关进度。返回主界面后再次进入会重新加载默认试场，自制布局需要从编辑器重新 `Load`。

## 3. 打开编辑器与界面操作

进入试场后，点击右上角 `Edit level`。编辑期间玩法暂停，鼠标用于编辑。

| 界面或操作 | 用途 |
| --- | --- |
| `Select / move` | 左键选中物体，按住左键拖动；点击空白取消选择 |
| 左侧元件按钮 | 进入连续放置模式，在场景内左键放置 |
| Esc | 取消放置或待完成的连线，回到选择模式 |
| `GRID` | 在 0.25 unit 和 1 unit 吸附间切换 |
| 鼠标中键拖动空白区域 | 平移编辑视野 |
| 滚轮（鼠标位于场景内） | 缩放编辑视野 |
| 底栏宽、高与 `Apply size` | 修改选中方盒元件的尺寸，主要用于地块、桥、门、星石 |
| `Set entry` | 将选中的星台设为关卡入口 |
| `Delete` 按钮或 Delete 键 | 删除选中元件；快捷键需要鼠标位于场景内 |
| `Return` | 退出编辑并继续当前布局，不自动保存文件 |

星槽、压力板和碎片不能通过底栏任意改碰撞尺寸；乐器建议沿用默认尺寸。当前没有运行时旋转工具、复制按钮和 Undo/Redo，请在大改前用新名称保存一个副本。

`New` 和 `Load` 会直接替换当前布局，未保存修改会丢失；`Save` 和 `Play test` 会覆盖同名 JSON，不另弹覆盖确认。

## 4. 第一次制作：碎片、石头与门

1. 先在顶部名称栏输入 `gallery_backup`，点击 `Save`，备份当前试场布局。
2. 点击 `New`，得到一块地面和入口星台。名称改为 `my_first_level`。
3. 在左侧选择 `Fragment`，在入口右侧、星弹能直射的位置放一片碎片。按 Esc 回到选择模式。
4. 放置 `Pressure plate` 和 `Stone`：压板贴近地面，石头放在压板旁边。石头推动后需要与压板感应区域相交；可在压板末端加一个低矮 `Solid` 挡沿，防止石头滑过头。
5. 在更右侧放置 `Gate`。用 `Select / move` 选中门，点击顶部 `Link signal`，再点击压板。连线后回到选择模式，随后试玩确认门的响应。
6. 确认入口星台上方及其旁边有足够的角色出生空间。点击 `Save`，再点击 `Play test`。
7. 试玩时从入口开始：发射收片、推石压板、观察门开启。
8. 点击右上角 `Stop test`，恢复试玩前保存的布局并回到编辑器，继续修改。

`Play test` 会先保存当前布局，再重开本关开始测试；试玩时的收片、推石、碎墙不会写回作者布局。`Stop test` 恢复的是本轮试玩开始时保存的布局。

## 5. 可放置元件与机关连线

| 按钮 | 用法 |
| --- | --- |
| `Solid` | 地面、墙和普通平台；可改宽高 |
| `Hazard` | 危险区，接触后返回星台 |
| `Checkpoint` | 安全星台；每关至少保留一个，并指定入口 |
| `Fragment` | 星弹收集品；新放置时自动生成独立 ID |
| `Platform socket` | 入槽后留下可踩的星影平台 |
| `Plate socket` | 入槽后星影压住该槽自带压板，可连接桥或门 |
| `Pressure plate` | 被星石或星影持续压住时输出开启信号 |
| `Bridge` | 信号开启时形成承重桥，失去信号后撤去 |
| `Gate` | 信号开启时解除阻挡；关闭位置有人或重物时等待净空 |
| `Stone` | 可推重物，可压板、垫脚 |
| `Lyre` | 星弹撞击后反弹并锁存开启，可作为门或桥的信号源 |
| `Drum` | 星弹撞击后产生鼓波，击碎预先关联且在范围内的脆墙 |
| `BrittleWall` | 可被星弹直接击碎，也可受关联手鼓影响 |

桥、门的连线顺序固定为：**先选桥或门 → `Link signal` → 点击压板、压板型星槽或里拉**。每座桥、门当前只有一个信号源，没有 AND/OR 多条件组合界面。未连线的桥、门不会按谜题预期响应。

星影桥的简单组合：放一个 `Plate socket` 和一座 `Bridge`，按上述顺序将桥连到槽。试玩时发射入槽，桥形成；R 召回完成后桥撤去。可踩平台需要 `Platform socket`，不要用背景装饰代替。

里拉门的简单组合：放一个 `Lyre` 和一扇 `Gate`，把门连到里拉。试玩时用星弹撞里拉，门保持开启，普通失败和当前谜题复位不会将它关回。

**手鼓限制：** 当前游戏内界面没有“选择鼓波目标墙”的操作。内置试场的手鼓已经配好目标，保存、加载会保留关联；新放置的手鼓不会自动关联附近墙。可先体验和修改内置试区；需要建立新关联时，在 Unity Editor 的 `StarInstrument` Inspector 配置 `Wave Targets`，或由熟悉关卡格式的人修改 JSON 的 `waveTargetIds`（引用脆墙记录的 `id`）。鼓波还受手鼓半径限制，只有靠近并不会自动成为目标。

## 6. 谜题分组与复位

左侧 `PUZZLE GROUP` 用于选择谜题组，`+ Puzzle group` 创建新组。新元件属于当前组；已有元件被选中时切换组，会将这个元件移入该组。只想切换后续放置组时，先点击场景空白取消选择。

每个区域放一个属于该组的星台。玩家激活该星台后，暂停菜单的“重置当前谜题”复位这一组的星石等对象，并重新计算压板、桥和门；全关唯一星影会被撤回。碎片、已碎的墙和已触发里拉继续保留。需要完全恢复初始状态时使用“重开本关”。

请把星台放在安全地面上，出生位置不要埋进地块、门或石头。入口检查失败时，状态栏会显示 `The entry dais has no clear respawn position.`；移开遮挡物或调整星台位置再试玩。

## 7. 保存、加载与分享

自制关卡保存在当前 Windows 用户目录：

```text
%USERPROFILE%\AppData\LocalLow\DefaultCompany\H-ONE\Levels
```

可以按 Win+R，粘贴上面的路径并回车。第一次 `Save` 后会创建目录，文件名类似 `my_first_level.json`。名称支持字母、数字、中文、连字符和下划线；空格等字符会被过滤，建议用简短名称区分副本。

- **保存：** 输入名称后点 `Save`。改名再保存可保留旧文件。
- **加载：** 在顶部文件列表中选择名称，再点 `Load`。
- **分享：** 把对应 JSON 发给对方；对方放进自己电脑的同一路径，再重新进入编辑器刷新列表，选择后 `Load`。
- **包内示例：** 将 `Examples` 中的 JSON 复制到上述 `Levels` 目录即可加载；首次进入时仍显示默认试场。`demo_gallery.json` 是完整机关试场布局；`demo_first_level.json` 是地面、入口、碎片、星石、压板、挡沿和门组成的简单连线示例。
- **保存范围：** JSON 保存布局、分组、入口、稳定 ID、尺寸和机关关联；不保存玩家的收集进度、当前星影或跨启动续关状态。

同名文件会被覆盖。复制 JSON 做新关卡时可改文件名，并在编辑器加载后改名称再保存；不要复制粘贴 JSON 内的单个元件记录而保留相同 ID。

## 8. 常见问题与当前边界

- **找不到 `Edit level`：** 需要先从主菜单进入试场，并使用本包附带的编辑器版本。
- **收不到碎片：** 用星弹命中，人形接触不收集。
- **压板没有反应：** 人形不计重；检查星石或槽内星影是否真正压在感应区。
- **第二个星槽不接受星弹：** 同时只能有一个星影，先按 R 并等待召回完成。
- **桥或门不响应：** 检查是否按“先桥门、后信号源”连线；里拉属于持续锁存信号，压板属于实时占用信号。
- **编辑后没有写入文件：** `Return` 不等于保存，请点 `Save`；`Play test` 也会保存。
- **按错操作想恢复：** 目前没有 Undo/Redo，加载上一次保存的副本。
- **新关卡仍有地图边界：** 当前运行编辑器沿用试场的相机和失败边界，没有修改边界的界面；先在现有试场范围内搭建。
- **为什么没有通关：** 本版本没有集齐碎片自动解锁的正式出口和章节流程，适合测试局部谜题。排箫、独立星纹开关、复杂逻辑组合也尚未提供。

随包 HTML 说明可直接用浏览器打开；TXT 说明可用记事本打开。需要 Unity Editor 中的场景制作工具时，另见仓库中的 `docs/05-关卡编辑器与M2元件.md`。
