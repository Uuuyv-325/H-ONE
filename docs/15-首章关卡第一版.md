# 首章关卡第一版（M3 / M4 / M5 增量）

日期：2026-11-10。用户本轮要求：优先有可用关卡；教学不用解释文字；操作与 HUD 随关卡推进逐步开放。这是首轮关卡实现与测试记录，不代表 P1/P2 美术音频签收或新玩家 3–5 分钟验收。

## 入口与文件

- `Assets/Game/Scenes/MainMenu.unity` 的开始按钮进入 `Chapter01_01.unity`，第一关出口进入 `Chapter01_02.unity`，第二关出口显示可重玩/回标题的章节完成菜单。
- `Assets/Game/Data/Levels/Chapter01_01.asset`、`Chapter01_02.asset` 显式列出各关 F1–F3、第二关 S1/S2 及下一场景；出口按必需 ID 集合判断。
- `Assets/Game/Data/Player/ChapterPlayerTuning.asset` 复用原玩家参数，仅将本版最大星弹路程设为 **8 unit**。这是为小房间与平台高度验证提出的调参值；Core / ShadowSlice / Gallery 的原配置不改。起跳高度仍约 2.2 unit，步速 4.4，召回 1 秒、重组约 0.5 秒、共用一次反弹。
- `ChapterFirstPassAuthoring.Create()` 只接受两个未使用的新场景路径。后续在已保存场景中编辑，不重建旧关卡，不运行 PlatformerSceneBuilder。新开关/排箫暂由场景直接持有，未扩展通用编辑器 JSON；正式场景不挂运行编辑器，避免导出时丢失专属组件。Core/ShadowSlice/Northline 与机关试场保留。

## 渐进提示与表现边界

`ChapterTutorial` 只控制表现开放，不锁输入、不发放进度。未学的操作仍可由熟悉玩法的玩家直接使用。第一次收片前隐藏收集 HUD；到发射区才显示蓄力 HUD；到星槽区才显示单影 HUD；第一关实际站上支撑或第二关到桥后才显示召回字形。失败/谜题复位保留学过的提示，整关重开重新教学。系统每个教学区只显示当前动作，键名字形读取 Input Actions。

教学为世界中的圈、形状、箭头、断续嵌线和循环幽灵：没有碰撞、不承重、不产生游戏事件。占槽/升台后更新演示动作；暂停冻结演示。首版没有人工配音或说明段落，也没有把所有键位条铺在开场。仍缺正式陶瓶壁画、独立手绘键帽/鼠标图案、玩家主动重播按钮和完整装饰区分验收。

`ChapterCameraLayout` 为每个教学区域配置镜头，反弹起点/弦面/目标尽量同框，塔区拉远容纳高处目标。小房间不沿用无条件低位跟随；重组重置相机历史。现有背景、角色、乐器与地形复用原 Delivery01/02，排箫/开关/出口/教学仍为项目内程序占位。来源快照和文件哈希见 `chapter-first-pass-manifest.json`，占位账目见 Checklist §12。

`ProgressCondition` 把碎片/锁存 ID 和实时信号分开。`StarSwitch` / `FlutePort` 是星弹扫掠的穿透触发器，不额外消耗反弹；预览只查询。`PanFluteLift` 使用已有 Rigidbody2D 的 Kinematic + FixedUpdate/MovePosition，普通失败保留运动目标，组复位回初始端点。排箫上下/开关新增短合成样音，经既有 SFX 总线播放；声音不决定机关结算，暂停/复位/卸载清理，正式音频仍待交。
