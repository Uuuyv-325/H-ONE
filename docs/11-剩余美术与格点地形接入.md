## 地图与玩法边界

采用“矩形区块内的格点铺图”，保留现有精确谜题尺寸、Collider、出生点和稳定 ID。没有强制把所有机关移到整格，也没有把现有地图清空重建。每个普通 Solid 用一个动态生成并清理的 Mesh；同一图集/材质，左右端与中段按列选图，深层使用独立土层切图，非整数宽高按 UV 裁切。旧 `Visual` SpriteRenderer 停用但节点保留，`GrassCells` 与碰撞根分离。

`CoreSceneAuthoring` 最终应用路径、`DeliveredArtAuthoring`、`LevelPieceFactory`、`M2SceneAuthoring.Resize`、Runtime Catalog、`LevelPieceMetadata.Apply` 和运行编辑器 resize 均覆盖新表现。旧灰盒仍可保留 P0 工具/轨迹/机关默认；不能因格点贴图接入就认定所有占位已清除。

圆形笔刷是本轮提出并实现的编辑用途：在现有编辑器勾选 `Round grass brush`，设置半径并点击 Scene View，按格心是否落在圆内生成行区块，可 Undo；现有地形区域跳过，避免重叠碰撞。它使用美术圆图作预览，实际可站区域由方形地形组成，不增加独立圆形平台。可继续按实用反馈调整笔刷，而不改动原图。

里拉和手鼓沿用 `StarPathSolver` 的同一次反弹预算。预览只计算，不播放受击、不改变机关/碎墙。真实飞行每个乐器每发至多触发一次；鼓波只影响显式目标中处于配置半径内的陶墙。直接星弹碎墙可穿过且不消耗反弹。新锁存/碎墙状态以稳定 ID 保存于本关 `LevelSession`，普通失败与当前谜题复位保留，整关重开清空。动画/波纹不决定判定；暂停冻结表现时间。声音层抑制乐器命中叠普通闷响；正式乐器音频未交付，不新增不合语义的声音冒充成品。

新 Prefab 为 `Lyre` / `Drum` / `BrittleWall`；工厂、运行 Catalog 和文档导出枚举只在末尾追加，保留既有枚举值。显式鼓波目标记录为稳定元件 ID，导入后重连；里拉可作为普通门的锁存信号源。Gallery 向右增加试验地面与 `04_Instruments` / `InstrumentDais`，原三个试区保留；这是素材试区，不是正式两关或完整教学。
