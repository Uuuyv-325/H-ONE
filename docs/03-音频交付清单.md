# 第一章音频交付清单

日期：2026-11-04。对应[架构与规则基线](01-整体架构与落地路线.md)和[美术交付清单](02-美术交付清单.md)。覆盖音效、音乐与环境声；不要求配音。下表数量是首章建议下单量，先做 P0 小样验证，再生产 P1/P2。

实施记录：M0/M1 已试装七个原创合成技术 WAV（48 kHz、24 bit、mono），通过玩法事件接入 Music/SFX Mixer 的 SFX 总线，暴露 `MusicVol` / `SFXVol`。这是核心反馈的接入样片；三乐器、正式声音设计、音乐、听感与响度验收尚未完成，不算整批 P0 通过，见[开发进度](04-开发进度.md)。

## 1. 声音方向与功能

原案确定：普通无特殊交互表面为闷响、特殊可撞物为“叮”、碎片为星铃、里拉琴承担反弹/成功和弦、手鼓承担鼓波/碎墙、排箫承担平台升降音高；失败是星光散开并快速重组。

声音应轻巧、清澈、有石质神庙的空间感，保持解谜时能思考的安静余量。使用拨弦、膜鼓、短木管气息、陶片与细颗粒星光构成统一语言。古希腊是音色设计方向，不宣称所有采样为历史复原；不默认加入现代军鼓、史诗铜管、枪炮冲击或人声旁白。

三个乐器必须可凭音色分辨：里拉是清楚的拨弦瞬态与短余韵；手鼓是温暖膜面低中频击打和短扩散；排箫是带空气的管音，升/降方向可辨。星铃比里拉更细、更短，不使用相同素材同时承担两种提示。

建议先用 D Dorian 音集 `D E F G A B C` 作首轮统一调性，关键确认音围绕 D/A，完整进度用短和弦收束。调性是本次制作建议，P0 可更改。**不能把语义音高做成任意随机 pitch**；只对脚步、陶碎等非定音乐器作很小变化。

## 2. 音效逐项列表

约定：变体数是可替换的独立录音/设计，循环需要独立 loop 文件；时长含自然尾音，除非列明“持续段”。P0 小样可从 P1 项中先取一个版本，后续补全数量。所有关键声音都配视觉反馈，声音不是唯一解谜线索。

## 4. 工程导出与响度要求

- **交付母版**：无损 WAV PCM，48 kHz、24 bit；声音制作工程与插件/采样说明同时交。MP3/AAC 不能作为母版，Unity 的压缩和 Load Type 由接入方针对包体/运行测量决定。
- **声道**：位置性短音效默认 mono，便于运行时左右定位；音乐与大环境底为 stereo。UI 可 mono 居中；有必要的立体声特殊设计另标用途，不交假双单声道大文件。
- **起音**：事件型短音起始前静音尽量 ≤10 ms；反弹、发射和收集必须即时。保留自然瞬态；微淡入淡出可消除点击，但不抹掉拨弦或鼓的攻击性。
- **循环**：loop 单独导出，注明 `loop_start_sample / loop_end_sample`，end 使用排他边界；若整文件循环则从 0 到文件总采样数。至少连续试听 10 次，无接缝点击、节奏跳变或混响抽吸。
- **尾音**：短效果保留自然尾，不能硬切。提供 dry 主版本；确需强空间声时另交 wet 示范及混响参数。常规空间感由 Mixer 统一处理，不能每条烘焙一套不同神庙混响。
- **电平**：短 SFX 首轮峰值参考 -6 至 -3 dBFS，保留余量，无削波；不对 0.2 秒短声机械套用 LUFS。音乐 full mix 首轮约 -20 至 -16 LUFS-I、真峰值 ≤-1 dBTP；stems 保持相对增益，以总和为准。环境底不要为了达到同响度而过度压缩。
- **最终混音**：游戏输出可先以约 -16±2 LUFS 的代表性游玩片段、真峰值 ≤-1 dBTP 为听测起点，不声称这是平台强制标准。最后在目标音箱/耳机和实际并发条件下调音，素材电平不是游戏音量。
- **调性/节拍**：定音素材标实际音高、调式、BPM；变体不得脱离统一调性。排箫上/下、收集 1/2/3 顺序明确，不靠随机选择。
- **命名**：`sfx_ch01_lyre_hit_01.wav`、`sfx_ch01_charge_loop.wav`、`mus_ch01_l01_lyre_stem.wav`；ASCII 小写；同一路径返修保留语义，版本号放交付包与 manifest，不随意让工程引用断开。

## 5. 运行接入与声音优先级

这是接入方需要实现的约定，声音制作者据此提供干净拆件。声音播放失败不能阻塞收集、开门或 0.5 秒重组。

### 总线和设置

```text
Master                         # MasterVol
  Music                        # MusicVol
  SFX                          # SFXVol
    Player
    Mechanisms
    Feedback
    Ambience                   # 可内部额外控制 AmbienceVol，仍服从 SFXVol
    UI
```

保留 `MusicVol` / `SFXVol` 名称便于一致接入，玩家设置持久化；UI 仍服从 SFX 静音，不另开绕过用户设置的声道。只有一个有效 AudioListener。首章用二维混音，必要时依据屏幕 x 位置做轻微左右声像，不依赖远距 3D 衰减导致屏外关键机关完全听不见。

### 去重、并发和生命周期

- **权威事件播放**：收集仅在 ID 首次入集合时；开门仅在条件从 false→true 时；压板按占用状态边沿。不可让 Animator、碰撞回调和状态事件各播放一遍。
- **互斥**：普通墙、里拉、手鼓等一次命中选择对应主音色，不叠通用墙击；成功入槽与失败声互斥。片收集与门节点提示同帧时优先片声。
- **层级**：失败/重组、反弹、碎片、关键机关反馈优先；脚步/环境/装饰次要。开门/过关时音乐短暂降低约 3–6 dB，约 0.1 秒进入、0.5–1 秒恢复，数值实听微调。
- **并发起点**：短 SFX 全局约 16 声部，脚步最多 2、陶墙碎裂最多 3、单个物体持续 loop 最多 1。达到上限优先替换最旧/最弱装饰声，不能静默丢掉首个关键进度提示。容量根据实测调整。
- **循环归属**：每个 loop 有明确 owner 和 handle；退出状态停止，不靠对象销毁时碰运气。蓄力、飞行互斥；推石、平台移动随实际运动停止；重组/切关清理对应对象；一次性尾音可短暂保留。
- **暂停**：冻结/暂停玩法 loop，UI 继续；音乐降低/滤波，不必完全停止。恢复时 loop 从状态判定恢复，不能重复创建第二个声源；暂停或失焦会取消蓄力，不再恢复旧蓄力音。
- **节流起点**：UI focus 约 80 ms、同一阻挡提示约 150 ms；连锁陶墙按一簇处理。重要收集/开关不能用全局 cooldown 意外吞掉不同目标。
- **音画时间**：关键瞬态对齐实际命中/状态边沿，目标误差不超过约 1–2 帧；不要等整段音频结束再切状态。0.5 秒重组与 1 秒召回均由玩法时钟决定。

## 6. 分批交付、文件包与验收

### 批次

1. **P0 声音样板**：脚步 1 条、蓄力 start+loop、发射 1 条、普通墙 1 条、失败 1 条、入槽 1 条、收集 1 条、里拉 1 条、手鼓/陶碎/排箫各 1 条、开门和弦 1 条、20–30 秒音乐方向小样。用同一段灰盒录屏测试三个乐器是否可辨、反馈是否遮挡。小样后续归入正式条目，不重复制作计费。
2. **P1 第一关**：补齐玩家/星影/收集/里拉/星台/首关门与通关、UI/教学、首关音乐和室内环境；在完整第一关里混音，重点测连续发射和 0.5 秒失败循环是否疲劳。
3. **P2 第二关与全章**：手鼓/鼓波/陶墙、星石/压板/桥、排箫/平台/开关/普通门、第二关音乐/过关、环境变体与标题；最终并发和设备混音验收。

```text
AudioDelivery/ch01_p1_v001/
  Source/                     # DAW 工程、实际用到的采样、插件说明
  Export/{SFX,UI,Music,Stems,Ambience}/
  Preview/                    # 音效分类试听、带游戏画面的混音视频

```

`manifest.csv` 必填：`asset_id, file, batch, sample_rate, bit_depth, channels, duration_sec, loop_start_sample, loop_end_sample, peak_dbfs, true_peak_dbtp, lufs_i, key, bpm, variant_group, dry_or_wet, source_project, revision`。不适用的字段写 `n/a`，不要给短 SFX 伪造 LUFS 精度。

`cue_sheet.csv` 必填：`event_id, asset_id, trigger, stop_condition, bus, priority, max_instances, cooldown_ms, gain_db, pitch_policy, pan_policy, linked_visual_id`。例如 `lyre.hit → SFX-19 → ME-04/FX-04`；定音乐器 pitch policy 标 `fixed`。程序最终资产配置以这张表为依据，变更时同步。

授权说明包含作者、原始采样/音源来源、可商用和可随游戏发行范围；第三方付费库遵守其授权，不要求违规转交原始库。无法交完整库时交可重建的冻结轨/分轨及说明，不能只交一个依赖缺失插件的工程。

### 验收清单

- WAV 规格、声道、时长、manifest 数量一致；无削波、底噪异常、无意长静音、丢尾音和未说明的节拍变化。
- 循环试听 10 次无接缝；随机变体连播自然，无同条连续重复；定音变体不走调，stems 从同一起点叠加能重建 full mix 的平衡。
- 不看画面时能分辨普通闷撞、里拉反弹、手鼓与鼓波、排箫升降、收集、入槽和失败；看画面并静音时仍能完成谜题。
- 连续失败/重组 10 次不刺耳，连续蓄力/取消不会残留循环；飞行中暂停/恢复、召回中暂停、重开谜题、切关后声音数量不持续增长。
- 鼓波同时碎多墙不过载；碎片和开门同帧时都有清楚的主次；音乐和环境不盖住关键瞬态。
- 在耳机、普通笔记本/桌面音箱和低音量下都能听清反馈；单声道折叠不丢关键声音；静音设置确实作用于所有相关总线。
- 最终在实际 Windows 构建中试听两关，记录机器/设备、响度设置与问题修订。音频波形或 DAW 内好听不能替代游戏内验收。

首章无需先引入第三方音频中间件。Unity AudioSource + AudioMixer 足够当前规模；后续如出现大量动态音乐分支再评估工具，不提前增加授权和工程依赖。
