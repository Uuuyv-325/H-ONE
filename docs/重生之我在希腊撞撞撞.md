《重生之我在希腊撞撞撞》完整策划案 V1.0

类型：单人 · 森林冰火人式碰撞解谜
核心：主角把自己像星星一样发射出去，撞击场景、收集道具、解开机关
主题：古希腊星空神话 × 神庙遗迹 × 希腊乐器机关
表达原则：少文字，多用画面、壁画、地贴、幽灵示范、音效、粒子表达
范围：本期完整细化 第一章“星弹发射”两关；第二、三章只做方向占位，机制 待商榷。

---

1. 项目概述

1.1 一句话卖点

把自己变成星星发射出去，在希腊神庙遗迹里撞击里拉琴弦、手鼓和星槽，收集星座碎片，解开机关之门。

1.2 核心体验

· 发射自己：人形状态可走跳推，蓄力后化为星弹飞出。
· 碰撞解谜：撞机关、撞脆墙、撞星槽，用撞击改变场景。
· 收集开门：收集星座碎片，点亮星座门。
· 希腊包装：多立克柱、陶瓶壁画、马赛克、月桂冠、里拉琴、手鼓、排箫。

1.3 目标平台与规模

· 单人横版解谜，短关卡制。
· 第一章 2 关，每关 3-5 分钟。
· 第二、三章各 1–2 关，机制待商榷，本期不制作。

---

2. 核心玩法规则

1. 主角平时为人形，可移动、跳跃、推星石。
2. 按住e’蓄力，出现星形轨迹（可调整）；松开发射成星弹。
3. 星弹飞行中不可控，撞墙可反弹一次。
4. 星弹撞到星槽会嵌入，留下星影；本体在最近星台重组。
5. 星影可压住压力板、形成临时平台、连通星桥；可远程收回，收回后星槽清空。
6. 星弹撞星座碎片即收集；撞星纹开关即点亮；撞脆陶墙即碎；撞乐器触发对应效果。
7. 失败不死亡：星光炸散，快速回最近星台；已收集碎片和已启动机关保留。

核心循环：观察发光机关 → 蓄力瞄准 → 发射星弹 → 碰撞/反弹/嵌入 → 收集碎片或启动机关 → 利用星影开路 → 星座门开启。

· 机关外观：星槽为马赛克星孔；压力板为神庙地砖；脆墙为陶瓶裂纹。

5.3 第一关：三片星座碎片（单人教学）

目标：收集 3 片星座碎片，点亮星座门。

流程：

1. A 区 直接撞：第一片碎片正对起点。入口陶瓶壁画一格：人形→星星→碎片；幽灵星影示范一次。
2. B 区 里拉反弹：第二片在侧高台，必须撞里拉琴弦反弹一次。地面马赛克星轨提示角度，琴弦振动发光。
3. C 区 星槽造平台：第三片在高处。发射嵌入马赛克星槽，留下星影形成临时星台；本体回星台，踩星影上台再发射收集。
4. D 区 出口：门上星座图随碎片逐个连线，全亮开门。

教学递进：直接撞 → 里拉弦反弹 → 星槽留星影造路。

5.4 第二关：星影机关（单人协作替代版）

目标：收集 3 片星座碎片，启动 2 个星纹开关，打开星座门。

流程：

1. A 区 星石压板：推星石压住神庙地砖压力板，打开第一道门。
2. B 区 星影压板+星桥：发射嵌入高处星槽，星影压住第二块压力板并形成星桥；本体回星台，趁机关开启跑过星桥，收集第二片碎片。
3. C 区 手鼓碎墙：撞手鼓机关，冲击波震碎脆陶墙，露出里拉琴弦。
4. D 区 里拉反弹开关：利用里拉琴弦反弹撞亮星纹开关，打开最后区域。
5. E 区 出口：收集第三片碎片，星座门亮满开门。

无文字教学：入口陶瓶壁画三格：推星石压板 → 发射嵌星槽留星影 → 跑过星桥。星影有月桂色轮廓提示可收回。

单人解谜核心：发射自己 → 留星影 → 本体回星台 → 利用星影和乐器机关改变场景。

7. UI 与反馈

· 左上收集栏：陶瓶碎片槽，集齐拼成星座图，不写数字。
· 蓄力：月桂星环蓄力，满蓄闪金光。
· 星影：半透明金色月桂轮廓，可远程收回。
· 可撞：边缘微光；不可撞：灰暗。
· 失败：星光炸散，回月桂星台。
· 成功：里拉琴短和弦 + 全屏星闪。
· 门锁：门上星座连线亮格，不写文字。

8. 美术与音效方向

8.1 美术

· 暗蓝神庙背景，金色星光主体，陶土红/黑绘点缀。
· 机关用马赛克、陶瓶裂纹、月桂纹、回纹区分。
· 可互动元素统一微光；不可互动灰暗。

8.2 音效

· 里拉琴：反弹、开门和弦。
· 手鼓：冲击波、碎墙。
· 排箫：平台升降音高。
· 星铃：收集碎片。
· 闷响：撞不可撞墙。
· 星光炸散：失败重置。

9. 教学与关卡节奏

1. 第一关 A 区：直接撞收集，建立“发射自己”的直觉。
2. 第一关 B 区：里拉弦反弹，建立“角度和反弹”认知。
3. 第一关 C 区：星槽留星影，建立“发射后本体回星台，星影留在场景”的核心规则。
4. 第二关 A 区：星石压板，复习推和压。
5. 第二关 B 区：星影压板+星桥，核心机制组合。
6. 第二关 C/D 区：手鼓碎墙、里拉反弹开关，组合乐器机关。
7. 出口：星座门连线亮满，短和弦收尾。

10. 验收标准

1. 单人、无文字，仅靠陶瓶壁画、幽灵星影、马赛克地贴、乐器音效能完成两关。
2. 第一关体现：直接撞、里拉弦反弹、星槽留星影造平台。
3. 第二关体现：星石压板、星影压板+星桥、手鼓碎墙、里拉反弹开关。
4. 希腊元素通过柱式、陶瓶、月桂、马赛克、里拉/手鼓/排箫表达，不靠文字说明。
5. 第二、三章明确标注“待商榷”，不进入本期制作。
6. 失败快速重置，已收集碎片和已启动机关保留，降低挫败。
