**总体决策：保留现有 Unity 工程，重构玩法层，新建第一章场景。** M0/M1/M2 的程序、场景与运行验证以[开发进度](04-开发进度.md)中的证据为准；2026-11-10 起默认入口为 `Assets/Game/Scenes/MainMenu.unity`，开始进入 `Chapter01_01.unity`，再经出口进入 `Chapter01_02.unity`；Core / ShadowSlice 保留为不进入构建的技术样例。运行编辑器仅在 Editor / Development Build 中提供。另有 H-ONE 菜单下的 Unity Editor 元件摆放工具。两关第一版详见 [15 记录](15-首章关卡第一版.md)，完整教学试玩及 P0/P1/P2 音画验收仍待完成，详见进度记录。

文档中的信息分为三种：

- **原案确定**：单人横版碰撞解谜；第一章两关，每关目标 3–5 分钟；三种乐器；金色星光、暗蓝神庙、陶土红/黑绘；失败保留进度；第二、三章暂不制作。
- **本次制作基线**：为让工程和资产制作能开始而提出的明确方案，例如 Windows 键鼠优先、二维绘本式美术、单个星影、共用一次反弹预算、补齐第二关排箫和第二个开关。这些不是原案已经写明的决定；修改时同步更新相关文档。
- **样机调参项**：速度、跳高、飞行距离、配色精确值、动画时长、音量等。先用灰盒和一组美术/声音样板验证，再批量生产。
