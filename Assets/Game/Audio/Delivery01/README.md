`Resources/ChapterAudio.asset` 显式引用六条交付。`CoreAudioFeedback` 在启动时读取默认配置，保留石/琴/鼓互斥和碎墙 75 ms 合簇；`ShadowFeedback` 独占入槽声，录制音 pitch=1，独立于旧召回音的变调。既有场景、首章两关和制作工具创建的 Core 反馈使用同一默认配置；缺失条目回退到技术声音。鼓波、蓄力、失败/重组、召回和收集仍为旧/程序占位。
