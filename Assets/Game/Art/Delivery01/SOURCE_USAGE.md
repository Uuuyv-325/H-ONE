# 美术素材说明

`bg-level1` 是第一大关的背景图片, `fg-level1-grass` 则是单独的草的前景.

`rock-dark` 和 `rock-light` 是两种不同点亮状态的岩石, 具体应用内容应结合具体玩法和策划案.

`main-menu` 是游戏的暂停页面, 其并非一个完整屏幕, 应当以叠加在暂停后游戏画面的方式嵌入, 并对游戏本身背景做适量虚化.

`IMG_6053`, `IMG_6054`, `IMG_6055` 是 `main-menu` 的差分, 石柱上的星星有不同点亮状态, 应该对应游戏内关卡进程, 具体使用方式仍要结合具体玩法和策划案.

`spawn-point` 为重生点素材; 点亮素材暂缺失, 具体是否需要这一素材仍要结合具体策划案.

`sprite_01` 为人物变身星星形态的 sprite 图, 由于并非严格对齐, 嵌入程序前仍需要自行调整. `turn_star` 为该动作的动图版本, 可以逐帧提取以供使用 (辅助或代之使用).

`sprite_02` 为星星形态的动画, 压力板动画和收集物的 sprite 图. 使用前仍需自行调整, 不存在对应的动图版本.

`sprite_03` 为人物行走动画, `walking` 为其动图版本. 具体使用说明和 `sprite_01`, `turn_star` 相同.

`title-screen` 为标题界面. 左侧为主要图片, 右侧 UI 待绘制.
